好，这次我专门 **结合语法 + 逻辑一步一步拆开讲**，让你彻底看懂这段代码。

我们只看这一段：

```tsx
return <NavLink
  to={item.link}
  className={({ isActive }) => {
    return isActive ? 'active' : undefined
  }}
>
  {item.title}
</NavLink>
```

------

# 一、先讲整体逻辑（先别管语法）

这段代码的意思是：

> 如果这个导航是当前页面，就给它加上 `active` 类；
> 如果不是，就什么都不加。

就是控制“高亮”。

------

# 二、从最外层开始拆语法

## ① 这是 JSX 语法

```tsx
<NavLink ... >
  {item.title}
</NavLink>
```

等价于：

```js
React.createElement(NavLink, {...}, item.title)
```

它就是在创建一个组件。

------

## ② `to={item.link}` 是什么语法？

这是 JSX 里传 props 的写法。

等价于：

```js
to = item.link
```

比如：

```js
item.link = "/discover"
```

那么最终效果是：

```tsx
<NavLink to="/discover">
```

------

# 三、重点来了：className 这一段

```tsx
className={({ isActive }) => {
  return isActive ? 'active' : undefined
}}
```

我们分 4 层拆。

------

# 第一层：为什么 className 是个函数？

正常我们写：

```tsx
className="item"
```

这是传一个字符串。

但是 NavLink 支持你传一个函数：

```tsx
className={(参数) => 返回值}
```

因为 NavLink 内部会调用这个函数。

它会这样做（简化版）：

```js
const result = className({ isActive: true })
```

然后把返回值当成 class。

------

# 第二层：`({ isActive })` 是什么语法？

这叫：

# ✅ 对象解构

假设 NavLink 内部给你传：

```js
{ isActive: true }
```

你可以这样写：

```js
function fn(obj) {
  const isActive = obj.isActive
}
```

但 ES6 提供了简写方式：

```js
function fn({ isActive }) {
}
```

意思是：

> 从传进来的对象里，把 isActive 这个属性拿出来。

------

# 第三层：箭头函数语法

```js
({ isActive }) => {
  return isActive ? 'active' : undefined
}
```

等价于普通函数：

```js
function (obj) {
  const isActive = obj.isActive
  return isActive ? 'active' : undefined
}
```

------

# 第四层：三元表达式是什么？

```js
isActive ? 'active' : undefined
```

意思是：

```js
if (isActive) {
  return 'active'
} else {
  return undefined
}
```

------

# 五、完整翻译成“人话”

当页面地址改变时，NavLink 会：

1. 判断当前路径是不是等于 to
2. 得到一个布尔值 true / false
3. 把这个值传进你的函数
4. 执行：

```js
return isActive ? 'active' : undefined
```

1. 如果返回：

```
'active'
```

最终 HTML 会变成：

```html
<a class="active">发现音乐</a>
```

如果返回：

```
undefined
```

最终 HTML 会变成：

```html
<a>发现音乐</a>
```

------

# 六、为什么返回 undefined？

因为：

```tsx
className={undefined}
```

就等于没有 class。

如果你返回空字符串：

```js
''
```

它还是会渲染一个空 class：

```html
<a class="">...</a>
```

虽然也能用，但写 undefined 更干净。

------

# 七、整个执行流程图（超清晰版）

浏览器当前路径
↓
NavLink 计算 isActive
↓
执行你写的函数
↓
返回 'active' 或 undefined
↓
决定是否加 class

这段代码的逻辑就是：

> “如果这个链接是当前页面，就给它加上 active 类。”
