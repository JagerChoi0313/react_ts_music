------

## 一句话先给结论

**重置（reset）样式的目的：**
 👉 **消除不同浏览器的默认样式差异，让页面从同一条起跑线开始。**

如果不重置，你写的 CSS 在 **Chrome、Edge、Firefox、Safari** 里看到的效果**可能不一样**。

------

## 浏览器到底“默认”了什么？

浏览器不是一张白纸，它自带一套 **User Agent Stylesheet（用户代理样式）**。

比如：

| 标签    | 浏览器默认行为          |
| ------- | ----------------------- |
| `body`  | 自带 `margin: 8px`      |
| `h1~h6` | 有不同大小、上下 margin |
| `a`     | 蓝色 + 下划线           |
| `ul`    | 左缩进 + 小圆点         |
| `img`   | 底部会留空隙            |

你**没写 CSS**，页面也能“看起来还行”，就是因为这些默认样式。

⚠️ 问题是：
 **不同浏览器，这些默认值不完全一样。**

------

## 现在逐条解释你这段代码：为什么要重置

### 1️⃣ `body, h1, h2 { margin:0; padding:0; }`

```
body,h1,h2{
    padding:0;
    margin:0;
}
```

### 如果不重置会发生什么？

- `body` 默认有 **8px margin**
- `h1 / h2` 默认有 **很大的上下 margin**

结果是：

- 页面一打开就“莫名其妙”有一圈空白
- 标题和内容之间间距你**控制不了**

👉 重置的本质是：

> **“间距由我来决定，而不是浏览器。”**

------

### 2️⃣ `a { text-decoration:none; color:#333; }`

```
a{
    text-decoration:none;
    color:#333;
}
```

浏览器默认：

```
a {
  color: blue;
  text-decoration: underline;
}
```

但现代网页里：

- 链接 ≠ 蓝色下划线
- 导航栏、按钮、卡片里都有 `a`

👉 重置后你可以：

- 自己决定 hover 样式
- 自己决定是否下划线
- 让 `a` 看起来像「普通元素」

------

### 3️⃣ `img { vertical-align: top; }`

```
img{
    vertical-align:top;
}
```

这个很多人一开始都**完全想不到**。

### 不重置会发生什么？

`img` 是 **inline / inline-block 元素**
 默认对齐方式是：

```
vertical-align: baseline;
```

结果是：

- 图片底部会多出一条 **神秘的空白**
- 在 `div` 或 `li` 里非常常见

👉 设置成 `top` 的意思是：

> **别按文字对齐，老老实实贴顶部**

------

### 4️⃣ `ul, li { list-style:none; }`

```
ul,li{
    list-style:none;
}
```

浏览器默认：

- `ul` 有缩进
- `li` 有小圆点 / 小方块

但现实开发中：

- 导航栏
- 菜单
- 下拉列表
- tab 切换

几乎全是用 `ul + li` 做的，但 **根本不需要小圆点**。

👉 重置就是：

> **把语义留下，把外观清空**

------

## 重置 CSS 的核心思想（非常重要）

你现在记住这句话就够了 👇

> **HTML 负责“是什么”，CSS 负责“长什么样”**

浏览器默认样式 ≠ 你想要的样式
 所以要先「清空默认」，再「重新设计」。

------

## Reset vs Normalize（拓展一下，给你种个种子 🌱）

你现在用的是 **Reset CSS** 思路：

- 简单粗暴
- 全部清零
- 常见于学习阶段 / 小项目

还有一种叫 **Normalize.css**：

- 不清零
- 而是“统一不同浏览器的差异”
- 更偏向工业级项目

但你现在用这种 **完全没问题，而且是最容易理解的**。
