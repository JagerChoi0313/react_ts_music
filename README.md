# React TS Music (网易云音乐仿站)

一个基于 **React + TypeScript** 实现的网易云音乐前端仿站项目，目标是尽可能还原网易云音乐的页面结构与核心交互体验。

## 项目定位

本项目为学习与实践用途，主要用于训练以下能力：

- 复杂页面拆分与组件化开发
- React 状态管理与数据流设计
- 音乐播放器交互实现（播放、暂停、进度拖拽、切歌）
- 歌词解析与时间同步高亮
- 接口联调与异步请求处理
- 前端工程化与样式组织

> 说明：本项目是**网易云音乐界面与交互的复刻练习（clone）**，用于技术学习展示，不用于商业用途。

## 技术栈

- React
- TypeScript
- Redux Toolkit
- styled-components
- Ant Design
- Axios

## 已实现功能

- 网易云风格首页布局与模块化页面结构
- 底部播放器样式复刻
- 歌曲详情获取与播放链接加载
- 音频播放控制（播放 / 暂停 / 上一首 / 下一首）
- 进度条点击与拖拽跳转
- 播放时间格式化展示
- 歌词解析与按时间匹配显示
- 榜单歌曲点击切换播放
